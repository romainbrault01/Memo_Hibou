Installer l'agenda
Sur iPad : ouvre cette page dans Safari, touche le bouton Partager (le carré avec une flèche), puis « Sur l'écran d'accueil ».
Sur tablette Android : dans Chrome, ouvre le menu ⋮ puis « Installer l'application ».
Sur ordinateur : dans Chrome ou Edge, clique sur l'icône d'installation à droite de la barre d'adresse. Sur Mac avec Safari : menu Fichier, « Ajouter au Dock ».
